# Givlah Bold webfont

Free for personal and commercial use. Full terms are in LICENSE.txt.

Add this to static/css/givlah.css to make the font available:

```css
@font-face {
  font-family: 'Givlah';
  src: url('../fonts/givlah/Givlah-Bold.woff2') format('woff2');
  font-style: normal;
  font-weight: 700;
  font-display: swap;
}
```

Apply it to a heading or brand selector with:

```css
font-family: 'Givlah', sans-serif;
font-weight: 700;
```

This font contains one Bold display style. The WOFF2 file is sufficient for
modern browsers; desktop font files and build sources are not needed here.
